# 골든벨 연습

마가복음 1~16장, 개역개정 성경 골든벨 연습 사이트입니다.

[사이트 열기](https://hadangs516.github.io/mark-goldenbell/)

- 장과 난이도, 여섯 가지 문제 유형, 5~30문항 선택
- 힌트와 제출 후 성경 구절 확인
- 오답을 개별 또는 전체 선택하여 복습
- 학습 기록은 사용 중인 브라우저에 저장

`index.html`은 배너와 파비콘을 포함한 단일 HTML입니다. `og-image.jpg`는 링크 공유 미리보기 이미지입니다.

개역개정 본문은 처음 조회할 때 인터넷 연결이 필요하며 대한성서공회 원문을 Jina Reader로 조회합니다. 개역개정 성경의 저작권은 재단법인 대한성서공회에 있습니다. 성경 전체 본문은 저장소에 포함하지 않습니다.
